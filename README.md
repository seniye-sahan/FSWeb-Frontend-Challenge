# FSWeb Frontend Challenge

A responsive frontend application developed with React as part of my Full Stack Development training at Workintech.

## Technologies

- React
- JavaScript
- Vite
- Tailwind CSS
- React Hooks

## Features

- Reusable React components
- Responsive design for mobile and desktop
- Component-based architecture
- State management with React Hooks
- User-friendly interface

## Installation

Clone the repository:

git clone https://github.com/seniye-sahan/FSWeb-Frontend-Challenge.git

Install dependencies:

npm install

Run the project:

npm run dev
